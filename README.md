## ✨ Projects & Highlights

### 🛍️ Amazon Homepage Clone
A pixel-accurate front-end clone of Amazon's homepage, built using only HTML and CSS. Includes:
- Navbar with logo, search bar, and icons
- Hero banner with full-width background image
- Product category grid with 8 box sections
- Footer layout

### 🧑‍💻 Personal Portfolio Website
A multi-page personal website with separate pages for Education, Experience, and Projects — styled with a shared CSS file.

### 📐 Flexbox Playground
Dedicated practice files exploring CSS Flexbox — direction, alignment, wrapping, and responsive layouts.

### 📋 Practice Sets (1–7)
Incremental HTML & CSS exercises covering:
- Box model, padding, margin, borders
- Typography and text styling
- CSS selectors and specificity
- Layout techniques
- Responsive design basics

## 🚀 How to View

No installations needed — just a browser.

**1. Clone the repository**
```bash
git clone https://github.com/datsaryan/Web-Development-Course.git
cd Web-Development-Course
```

**2. Open any file in your browser**
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

Or drag and drop any `.html` file directly into your browser.
